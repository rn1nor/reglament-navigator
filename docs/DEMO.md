# Сценарий демонстрации (7 минут)

Готовая запись: `demo/navigator_demo.mp4` (курсор и нажатия показаны на экране, подписи к шагам). Перезаписать после изменений:

```bash
.venv/bin/pip install playwright imageio-ffmpeg
```

```bash
NAVIGATOR_KB=data/kb/org .venv/bin/streamlit run navigator/ui/app.py --server.port 8601 --server.headless true
```

```bash
.venv/bin/python scripts/record_demo.py --url http://localhost:8601 --out demo/navigator_demo.mp4
```

Вторая команда выполняется в отдельном терминале и остаётся работать на время записи.

## Подготовка к живому показу

```bash
make ui-org
```

Интерфейс на http://localhost:8501 по готовой базе `data/kb/org` (20 файлов организаторов, 28 документов).
До показа задайте один любой вопрос: первый ответ медленнее из-за загрузки моделей поиска.
Все вопросы ниже есть на стартовом экране и в блоке «Ещё примеры» (файл `data/eval/demo_questions_org.yaml`).

## Что проговорить

- Ответ собирается только из положений документов. Каждый шаг проверяется: цитата существует и совпадает с текстом, документ действует, редакция актуальна.
- Порядок действий берётся из раздела документа с процедурой в порядке документа, а не набором разрозненных выдержек.
- Если опоры нет, система отказывает или просит уточнить и показывает, какие документы проверила.
- База закрыта для внешних API по условию кейса; модель подключается локально через тот же интерфейс.
- Новые документы добавляются без кода: файлом, ссылкой или обходом раздела сайта, затем «Переиндексировать базу».

## Если что-то пошло не так

| Ситуация | Действие |
|---|---|
| Первый ответ долгий | Модели загружаются один раз. Заранее задать прогревочный вопрос |
| Не хватает памяти | `NAVIGATOR_USE_DENSE=off NAVIGATOR_USE_RERANKER=off make ui-org`: режим BM25 без моделей |
| Анализ влияния не загружает файл | `.venv/bin/python scripts/impact.py --kb data/kb/org --new data/demo/org_prikaz_demo_izmeneniya_zaimstvovanie.txt` |
| Нужен пример без интерфейса | `examples/README.md`: 12 сценариев с ответами и источниками |
